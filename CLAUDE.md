# Claude entry point

Read and follow [AGENTS.md](AGENTS.md), then [the team workflow](docs/TEAM_WORKFLOW.md) and your assigned task in [the board](docs/TEAM_BOARD.md).

Those files are the shared policy for every provider; this file does not duplicate it. Use only your assigned worktree and paths. Do not build Unreal or create tests for every small edit. Hand off to the integration owner under the assigned validation tier. The user merges PRs.

[Direktor (2) is the sole producer](docs/PRODUCER.md). Finish existing assignments and record results in your own handoff/sub-board. Queue subsequent tasks through the producer; do not independently start another batch or a second writer in an owned worktree. Existing desktop chats remain the owners even when the producer also has CLI access.
