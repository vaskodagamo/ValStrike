# Environment kit source models

Original ValStrike hard-surface models, created with Blender 5.2.2 LTS
(`d13f752e3b9c`) on 2026-11-03. This is a small stylized treatment study for
`PLAY-02`, not a completed gameplay or map-art milestone.

## Files

- `build_environment_kit.py`: editable procedural modeling source.
- `VS_Environment_Kit.blend`: editable native scene. The five `*_SOURCE`
  collections hold canonical meshes at identity transforms; source objects are
  hidden individually. Unhide the desired source object to edit it.
- `Exports/*.fbx`: five independent real mesh exports, one visual mesh per file,
  with one `UCX_*_00` convex collision box for each solid piece. The decorative
  vent has no collision mesh.
- `mesh_validation.json`: measured source and Blender FBX round-trip evidence.
- `Previews/VS_Environment_Kit_Actual_Meshes.png`: Cycles render of the actual
  source meshes, using linked display copies. This is not an Unreal screenshot.

The `.blend` also contains a `PRESENTATION_linked_meshes_no_export` collection
with arranged linked meshes, camera, ground, and two soft lights. Those objects
are presentation helpers and are excluded from the FBX exports.

## Coordinates and materials

Blender source is Z up, front **-Y**, centimeters (`scale_length = 0.01`). Walls
and pillars use the minimum-X/Y/Z base corner; crate, cover, and vent use the
bottom center. All canonical source transforms are applied. FBX stores the
declared units, with `global_scale=1`, `FBX_SCALE_UNITS`, `apply_unit_scale=True`,
`axis_forward='-Y'`, `axis_up='Z'`, and no baked space transform. Unreal's
left-handed scene conversion was verified to reflect Y: native front is +Y,
and architectural pivots are minimum X / maximum Y / minimum Z. The native
import and fresh-reopen reports record that measured result.

Four shared, solid-color materials use original sRGB palette values:

| Material | sRGB | Roughness | Metallic |
| --- | --- | --- | --- |
| M_VS_Plaster | #C8B89E | 0.86 | 0 |
| M_VS_PaintedMetal | #416F70 | 0.70 | 0 |
| M_VS_Trim | #303C41 | 0.78 | 0 |
| M_VS_Accent | #D39B58 | 0.74 | 0 |

Colors are converted from sRGB to linear in Blender. No image textures,
normal maps, downloaded meshes, external fonts, or add-ons are used. Geometry
is original procedural work by Codex for this project; no third-party asset
license or attribution dependency is introduced.

Every convex source face receives a separate UV tile, then is triangulated.
Both UV channels are inside 0–1 with nondegenerate triangle UVs and disjoint
face tiles. `UV1_Lightmap` is available for optional lightmaps, but no static
light bake or texture-density acceptance is claimed. Current materials do not
sample either UV channel. The exposed panel faces are separated in depth to
avoid coplanar surface flicker.

## Regenerate and verify

From the asset worktree root, using the verified local Blender installation:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup \
  --python-exit-code 1 \
  --python Art/Source/Environment/Models/build_environment_kit.py
```

This rebuilds **all files generated by this script**, including exports, scene,
report, and preview. It overwrites those outputs; preserve hand edits before
running it. Coordinate regeneration with the Unreal import task, then reimport
and reverify the native assets. It does not create or edit `.uasset` or `.umap`
files. `--factory-startup` avoids unrelated locally installed add-ons, and
`--python-exit-code 1` ensures a failed assertion reports a nonzero process exit.

The script measures dimensions and pivots, checks closed manifold triangle
shells and positive signed volume, checks UV bounds/areas, then reimports each
FBX and compares actual world-space bounds, two UV channels, and collision
counts. A successful run prints `VALSTRIKE_MESH_KIT_SUCCESS` after rendering.

The solid meshes deliberately combine overlapping closed chamfered parts.
Collision uses one conservative full-envelope convex box: small chamfers and
inset surfaces are not separate collision recesses. Final collision, sightlines,
movement clearance, runtime materials, and performance need gameplay testing;
the source checks alone do not establish them.
